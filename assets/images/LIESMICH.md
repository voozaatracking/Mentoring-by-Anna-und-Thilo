# Bilder

Hier liegen die Bilder der Seite unter ihren Zielnamen, zum Beispiel `hero-heide.jpg`.

Ablauf und Zuordnung der Originalnamen: siehe README im Hauptordner, Abschnitt Bilder.

Kurzfassung:

1. Originaldateien in diesen Ordner oder ins Hauptverzeichnis legen und mit `git add` aufnehmen.
2. `npm run bilder:umbenennen`
3. `npm run bilder`
